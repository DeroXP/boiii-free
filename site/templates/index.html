01What it does

Built for big mod stacks.

BOIII runs one mod at a time. Xerces runs the whole stack, keeps the game steady while it does, and tells you plainly when something does not fit.

01

Mods, stacked

Turn your Workshop mods on and put them in order; the top one is the main mod. Xerces works out a plan, says which mods or maps will not go together, and the game loads them all.

02Install

Four steps, no installer.

Xerces is a folder you unzip. Your settings live in %LOCALAPPDATA%\Xerces, so a new version is a new folder.

  1. Own Black Ops III on Steam

    Windows 10 or 11, 64-bit, with the game installed and Steam signed in. Your mods come from your Workshop subscriptions.

  2. Download and check it

    Get the zip from the download page and compare its SHA-256 with the one printed there: Get-FileHash .\{{latest_file}} in PowerShell.

  3. Unzip into a folder of its own

    For example C:\Games\Xerces. Not inside the Black Ops III folder, and not in a folder OneDrive syncs, where the game can fail to start.

  4. Start Xerces.exe

    Only Xerces.exe: it starts the game itself, with the mods you picked. The first start reads your Workshop folder once; later starts are quick.

04Questions

Before you ask.

Do I need to own the game?

Yes. Xerces starts your own Steam copy of Black Ops III, at a build it supports, with Steam running and signed in to the account that owns it. It does not include or download the game.

Does it touch official matchmaking?

No. Xerces plays offline and on games players host themselves. It never connects to official Call of Duty matchmaking.

Windows says it protected my PC. Is that right?

Windows SmartScreen warns about programs that are not code-signed yet. Check the zip's SHA-256 against the one on the download page first; if they match, choose "More info", then "Run anyway". Signed releases are planned.

Steam updated Black Ops III. Now what?

Xerces only starts game builds it knows, and says so on Home when the build is new. Play through Steam until a Xerces release supports the new build. Do not keep or restore an older game build for Xerces.

What does Xerces send over the network?

Crash reports while they are on (Settings > Privacy turns them off and deletes the ones sent), the public server list, your Steam client's usual traffic, and your friends list once you sign in. The guide lists all of it.

A mod or map does not work with my stack.

Check Known issues first. Then send the game's log from Diagnostics, or the crash report if it crashed: they name the mods, the map and what the game was doing.

Is it open source?

Yes, under the GNU GPL version 3. Every release says which commit it was built from, and anyone can rebuild it from the source.
