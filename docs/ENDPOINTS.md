# Outbound endpoints

Every host the inherited client can contact, from the code on `xerces-main`
(upstream `beta` f8f7b735 plus `mod-stack`), 2026-11-04. M0 item 4 in DESIGN.md;
the decisions are D9, D14 and D15 (DESIGN.md 0.2 and 16.8).
`tools/ci/check_hosts.py` fails when code adds a host that is not listed in
`tools/ci/hosts.json`.

D14 and D15 are build switches (`src/client/xerces/switches.hpp`), off by
default: `premake5 ninja --with-ezz-social` or `--with-upstream-downloaders`
builds the upstream behaviour back in.

Joining a server with a missing Workshop item opens its page in the Steam client
when you agree (`steam://url/CommunityFilePage/<id>`), so Steam downloads it.
Joining a server on one of the game's own maps that your game lacks says the
server uses DLC you don't own or haven't installed, and offers Black Ops III's
store page in the Steam client (`steam://store/311210`). Upstream opened a page
on Ezz's forum instead.

Removed by D9 (2026-11-05), so no code in the repository or in `boiii.exe` names
these hosts any more: `archive.org` (`main.cpp`'s replacement `BlackOps3.exe`
and the old launcher's Patches tab) and `api.github.com` (the old launcher's
version picker, which ran upstream's release builds).

The old launcher's HTML and JS are not in `boiii.exe`. It loads them from the
data folder: `XERCES_DATA_PATH` if set, otherwise
`%LOCALAPPDATA%\boiii\data\launcher`. With the repository's `data\` the picker
and the Patches tab are gone. A data folder that upstream's updater installed
still has them, with the `api.github.com` request and the archive.org link,
because nothing replaces those files: upstream's updater is off and Xerces' own
(D16) is not built yet. Even then `boiii.exe` downloads and runs nothing else:
its launch handlers ignore the picker's exe arguments and start this build.

Addresses never appear in Xerces logs (DESIGN.md 15.1). The backend's host
joined this list on 2026-11-05 for crash reports; accounts and friends follow in
M5, the relay in M6.

The crash dialog and Settings > Privacy name
`https://github.com/DeroXP/boiii-free/issues` for reporting a crash by hand; it
opens only when the player clicks it. The crash dialog no longer names
`dc.ezz.lol`.
