# Outbound endpoints

Every host the inherited client can contact, from the code on `xerces-main`
(upstream `beta` f8f7b735 plus `mod-stack`), 2026-11-04. M0 item 4 in DESIGN.md;
the decisions are D9, D14 and D15 (DESIGN.md 0.2 and 16.8).
`tools/ci/check_hosts.py` fails when code adds a host that is not listed in
`tools/ci/hosts.json`.
